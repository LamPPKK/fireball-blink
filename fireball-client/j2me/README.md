# ☕ Fireball Client for Java ME (MIDP 2.0 / Feature Phones)

Dedicated thin-client MIDlet for legacy and feature phones connecting to [Fireball Server](../../fireball-server/).

---

## 🌟 Highlights
- **Micro Footprint**: JAR size `< 40KB`, memory usage `< 1.5MB RAM`.
- **Opera Mini Style Streaming**: Offloads 100% of JavaScript and rendering to the server.
- **2G/3G GPRS Optimized**: In-memory tile cache minimizes network bandwidth consumption.
- **D-Pad Virtual Cursor**: Navigate desktop web pages smoothly using a numeric keypad and D-pad.
