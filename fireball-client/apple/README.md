# 🍎 Fireball Client for Apple Platforms (iOS, iPadOS, macOS, visionOS)

Native Swift 6 & SwiftUI thin streaming client for Apple devices connecting to [Fireball Server](../../fireball-server/).

---

## 🌟 Highlights
- **Universal App**: Runs natively on iPhone, iPad, Mac (Apple Silicon & Intel), and Apple Vision Pro.
- **MetalKit Accelerated Video Stage**: Sub-millisecond frame rendering via Metal textures.
- **Biometric Keychain Pairing**: Saves paired server tokens in the iOS/macOS Secure Enclave.
- **Trackpad & Magic Mouse Support**: Native pointer, gestures, and scrolling.
